# nf-core module provenance

Modules were copied from the local nf-core/modules checkout at commit
`fb8dd13ce49b79f843627df4a51ebfad5f9ba49c` (2026-11-08). The nf-core modules
are MIT licensed; their copyright notices are retained. Only the relevant
module and its environment and metadata files are included.

Local modifications are confined to stub behavior: Hostile and RGI emit a
placeholder version in stub mode; RGI stubs use sample-specific output names;
Sylph and kallisto stubs write minimal valid tables for matrix tests. Normal
analysis commands are unchanged.
